### 01 — เกี่ยวกับผม

ผมเป็นนิสิตสาขาเทคโนโลยีสารสนเทศ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตกำแพงแสน มีความสนใจในการพัฒนาซอฟต์แวร์ การเขียนโปรแกรม และการพัฒนาเว็บไซต์เพื่อนำเทคโนโลยีมาประยุกต์ใช้แก้ไขปัญหาในชีวิตจริง

ผมให้ความสำคัญกับการเรียนรู้ผ่านการลงมือสร้างโปรเจกต์ ตั้งแต่การวางแผน ออกแบบ พัฒนา ไปจนถึงการทดสอบระบบ
